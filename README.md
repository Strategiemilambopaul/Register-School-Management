# Register-school-management
Register-school-management is an online site which allows great numbers of parents to register their children without any possible risk.
The site contents differents parts or layourt such as :
-   admin panel
-   user panel
-   contact system
-   inscription panel 
-   information panel which seems like a notice panel

# Building
This project was built with different technologies so that we can handle this one.
- some html , css and js for the front-end
- php (+ POO ) for building our system
- sql (MYSQL) to connect our project to the database
